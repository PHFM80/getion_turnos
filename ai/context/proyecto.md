# Proyecto

## Descripción
Sistema backend para gestión de turnos automatizados con integración a WhatsApp.

## Objetivo
Permitir a empresas gestionar turnos, disponibilidad y comunicación con clientes de forma automatizada.

## Tipo de sistema
Backend en Django orientado a múltiples empresas (tipo SaaS simple, no multi-tenant complejo).

## Usuarios del sistema
- Administrador del sistema
- Empresa (dueño o staff)
- Cliente final

## Funcionalidades principales
- Gestión de empresas
- Gestión de servicios y duración
- Gestión de agenda y disponibilidad
- Reserva de turnos
- Manejo de conversaciones tipo bot
- Notificaciones (WhatsApp / email)

## Integraciones externas
- WhatsApp Business API
